# ph-connector

The Product Hunt connector (`custom.producthunt`) for Muse: `bin/client.py`
is the registered API client, `CONNECTOR.md` documents the connection, and
`connector.yaml` is its registration manifest. Authentication is held by
Muse's registered connection — no credentials live in this repo.

Live copy runs from `~/workspace/custom-connectors/custom.producthunt/` on
the Muse VM.
